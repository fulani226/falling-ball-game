# Falling Ball / Paddle Game

[Play Falling Ball](https://fulani226.github.io/falling-ball-game/)

Original standalone HTML game recovered from `falling_ball_game.html`. The source is preserved unchanged as `index.html`.

## Play

Move your mouse to control the green paddle. Keep the red ball bouncing off the paddle and walls. If it reaches the bottom, Game Over appears; dismissing the alert reloads the game.

## Run locally

Download `index.html` and open it in a desktop browser. No dependencies or build step.

## Hosting

GitHub Pages serves the root of the `main` branch.
